Bu klasor bag/luggage/person icin YOLO formatli etiketli veri kokudur.

Dosya yerlestirme:

- Egitim goruntuleri: `data/bag_yolo/images/train/`
- Validation goruntuleri: `data/bag_yolo/images/val/`
- Egitim etiketleri: `data/bag_yolo/labels/train/`
- Validation etiketleri: `data/bag_yolo/labels/val/`

Her goruntu icin ayni isimli bir `.txt` etiket dosyasi olmali.

YOLO class id:
- `0` = bag
- `1` = luggage
- `2` = person
